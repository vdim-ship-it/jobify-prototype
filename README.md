# Jobify Prototype

Mid-fidelity clickable prototype for Jobify, a job readiness platform that helps young Nigerians build in-demand skills, gain real work experience and turn it into sustainable income.

Built for the ALU Capstone Proposal and Prep: Field Mission Assignment.

## Screens
1. Welcome
2. Skills and interest check
3. Home and project dashboard
4. Project with mentor feedback
5. Portfolio, AI resume builder and job matches
6. AI interview practice

All content is sample content for user testing.

## Run it
Open `index.html` in a browser. No install or build step is needed.

To publish it, turn on GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder).

## Layouts
- **Phone (under 900px wide):** the original app layout, starting at the welcome screen.
- **Desktop (900px and wider):** a landing page (hero, how it works, features, who it is for, mission), then the app with a top navigation bar and two-column screens.

## Files
- `index.html`: landing page and app structure
- `styles.css`: app styling, including the desktop layout
- `landing.css`: landing page styling (desktop only)
- `script.js`: screen navigation and interactions
